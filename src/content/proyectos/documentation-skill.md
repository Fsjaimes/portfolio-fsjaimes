## Qué hace

Genera hasta seis tipos de documento: resumen funcional, documentación técnica, instalación, soporte y manual de usuario. Antes de escribir hace unas preguntas sobre el proyecto y lee el repositorio si tiene acceso.

## Salidas

HTML de un solo archivo con navegación lateral y figuras interactivas, o Markdown con diagramas Mermaid.
